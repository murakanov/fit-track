FIT TRACK — MVP 0.1

Содержимое:
- index.html — приложение
- manifest.webmanifest — параметры установки PWA
- sw.js — кэширование для офлайн-режима
- icon-192.png / icon-512.png — иконки

Важно:
1. Это прототип с демонстрационными упражнениями, не индивидуальная тренировочная программа.
2. В текущей версии таймер работает в открытом приложении. На iOS фоновые таймеры и звук при заблокированном экране имеют ограничения; это нужно отдельно тестировать.
3. История и масса тела хранятся локально в браузере на устройстве. Очистка данных Safari может удалить их.
4. Оценка калорий приблизительная (условно 5 MET) и зависит от введённой массы тела, реальной интенсивности и пауз.
5. Чтобы установить как PWA, файлы нужно разместить на HTTPS-хостинге, открыть ссылку в Safari и выбрать Поделиться → На экран Домой.
